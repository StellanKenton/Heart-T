# 离线 ECG 波形查看器

读取 CSV 的 `ch2_raw`，显示 CH2 原始波形、经 0.5–40 Hz 带通及 50.07 Hz 陷波后的 CH4 波形，以及新增的瞬时心率图。若 CSV 有 `elapsed_ms` 列，则用它计算 RR 间期和横轴时间；否则按 500 Hz 生成时间。波形滤波和 R 峰检测按 500 Hz 采样率进行。

每两个相邻 R 峰形成一个 RR 间期，瞬时心率为 `60 / RR(秒)`，绘制在后一个 R 峰的时间点。RR 超出 0.30–2.00 秒时，该心率点留空；附近最多 5 个 RR 中至少有 3 个合理值时，还会剔除偏离其中位数超过 30% 的 RR。右侧总心率根据保留的 RR 间期计算，并显示有效 RR 数量。

## 运行

在仓库根目录执行：

```powershell
py -3 OfflineWaveHandle/main.py D:\data\heart_raw.csv
py -3 OfflineWaveHandle/main.py D:\data\heart_raw.csv --save D:\data\waveform.png
```

省略 CSV 路径时会打开文件选择框。依赖 `numpy`、`scipy`、`matplotlib`。界面可平移和缩放三张图的显示范围、标记两个测量点，并导出仅含 `ch2_raw` 和 `ch4` 的 CSV。

点击 CH2 或 CH4 波形中 R 峰前后约 200 ms 的位置，会选中最近的 R 峰，自动调整 CH4 纵轴以看清该心搏，并在 CH4 波形上标出单搏切片、QRS 起点、Q 终点、R 峰、S 起点及 S/QRS 终点；右侧显示该心搏的放大切片及 Q、S、QRS 宽度（毫秒）。单搏切片最多包含 R 峰前 300 ms 和后 400 ms，遇到相邻心搏时以两峰中点截断。Q 宽度为 Q 起点到 Q 终点，S 宽度为 S 起点到 S 终点；QRS 宽度有 Q 波时从 Q 起点算起，无明显 Q 波时从 R 上升沿起点算起，终点为 S 终点。R 峰通过局部突起程度定位，Q/S 边界按各自的局部波形估计，避免整搏基线漂移造成的大量漏判；边界不清楚时仍显示 `N/A`。点击 `Point 1` 或 `Point 2` 后，下一次点击用于原有的手动两点测量。

| 文件 | 职责 |
| --- | --- |
| `main.py` | 解析参数、选择文件、启动加载和绘图 |
| `data.py` | 读取 CH2、滤波生成 CH4、检测 R 峰、计算 RR 和瞬时心率、过滤异常 RR、切片及测量单搏、导出数据、按视口取值 |
| `waveform.py` | 显示两条波形、独立心率图、单搏切片及交互控件，只从数据对象取值 |
| `test_data.py` | 验证 RR 异常值过滤、瞬时心率及单搏测量 |

绘图按视口宽度抽样并保留局部极值，拖动时合并短时间内的连续刷新，以减少大文件操作时的卡顿。
