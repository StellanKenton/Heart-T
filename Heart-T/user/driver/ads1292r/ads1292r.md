# ADS1292R 驱动

依据本机 `D:/BaiduNetdiskDownload/ads1292.pdf`，重点对应第 40、41、43、49–61、65 页。

| 信号 | 接线 / 要求 |
| --- | --- |
| START | PB13，输出，高电平持续转换 |
| PWDN/RESET | PB14，输出，低有效，共用掉电/复位功能 |
| DRDY（用户标注 DREDY） | PB15，输入，下降沿 EXTI15_10，优先级 5 |
| CS / SCLK / DOUT / DIN | PA4 / PA5 / PA6 / PA7 |
| CLKSEL | 模块必须配置为高，使用内部 512 kHz 振荡器；软件不控制此引脚 |
| 供电 | 本驱动使用内部 2.42 V 参考；模块供电、地和模拟前端由硬件提供 |

初始化：释放 PWDN → 等待 1 s → 100 µs 复位脉冲 → 等待复位完成 → SDATAC → 校验 ID=0x73 → 写入并读回配置 → 等待参考稳定 200 ms。
初始化完成后保持停止，`ads1292rStart` 拉高 START。任何初始化中途失败都会拉低 PWDN。
默认 500 SPS、连续转换、两个通道增益 6、正常电极输入；呼吸、导联脱落检测及 RLD 默认关闭。
RESP1 的固定位 1 和 RESP2 的固定位 0 均置 1；RESP2 使用内部 RLD 参考；LOFF_STAT.CLK_DIV 保持 0。

## 配置

先 `ads1292rLoadDefaultConfig`，修改所需字段，再由唯一设备任务调用 `ads1292rInit` 和 `ads1292rStart`。

| 字段 | 取值 / 必填规则 |
| --- | --- |
| `rate` | 125 / 250 / 500 / 1000 / 2000 / 4000 / 8000 SPS 对应枚举；高采样率需要缩短读取间隔 |
| `gain[2]` | 每通道 1 / 2 / 3 / 4 / 6 / 8 / 12 对应枚举 |
| `input[2]` | NORMAL / SHORT / TEST；TEST 自动开启内部 1 Hz 方波 |
| `respiration` | true 开启通道 1 呼吸调制与解调，32 kHz；两路 input 必须为 NORMAL；通道 2 可用于 ECG |
| `respirationPhase` | 0..15，每步 11.25°；根据实际模块模拟网络调整 |
| `leadOff` | true 开启两路正负输入的直流导联脱落检测 |
| `rldSense` | RLD_SENS 寄存器原始值；默认 0；根据模块 RLD 接线选择 |

启用呼吸或 RLD 前应确认模块确实连接了对应模拟网络；软件无法推断模块电路。
本驱动只支持单个 ADS1292R，不接收 ADS1292/ADS1291 ID，不支持外部时钟或级联。

## 调用和数据

| API | 上下文 / 行为 |
| --- | --- |
| `ads1292rInit/Start/Stop/PowerDown` | 调度器启动后，唯一设备任务；掉电后必须重新 init |
| `ads1292rReadRegisters/WriteRegisters` | 唯一设备任务，停止状态；调用者保留寄存器固定位；禁止写 ID、单次转换及 CLK_DIV=1 |
| `ads1292rReadSample` | 唯一设备任务；DRDY 高返回 NOT_READY；DRDY 低用 RDATA 读取 24 位状态和两路有符号 24 位样本 |
| `ads1292rDrdyIrq` | 仅 ISR；只增加边沿计数，不收发 SPI，不输出日志，不调用内核 |
| `ads1292rGetLatest/GetStats` | 任意任务，只读临界区快照；不能在 ISR 中调用 |

原始电压换算：`channel * 2.42 / (gain * 8388608)` V。
通道 1 开启呼吸后，原始码属于呼吸解调结果，需根据模拟网络标定，不能直接解释为阻抗。
状态字最高 4 位应为 0xC，否则返回 FRAME 错误；初始化只校验可写位，排除实时 GPIO 和脱落状态位。
成功返回 `1`；ADS 错误 `-20` 参数、`-21` 状态、`-22` ID、`-23` 配置校验、`-24` 尚未就绪、`-25` 帧格式；SPI/RTOS 失败原样透传。

SensorTask 已接入默认初始化与采集，每 1 ms 检查 DRDY，每秒输出采样计数、丢样估计和最新双通道码。
SensorTask 栈为 256 个 32 位字（1 KB）；RTOS heap 为 7 KB，覆盖任务、idle、timer 及内核对象预算。
为适应 32 KB Flash，CMake 对新增驱动和 HAL 使用 `-Os`，保留 Debug 符号。
算法任务可用 `ads1292rGetLatest` 获取最新数据；这里没有样本 FIFO，不能依靠较慢的算法任务保留全部 500 SPS 样本。
`sequence` 是读帧开始时的 DRDY 边沿计数；`missedCount` 根据边沿间隔估计，跨读帧边界时不保证精确对应转换编号。
`tickMs` 是任务开始读帧的近似时间，不是精确转换时间。高采样率/全量算法处理需另行接入队列及更快采集入口。

验证入口：`py -3 develop/quick_deploy.py build`。烧录和 RTT 同样使用 Device Tool 对应入口。
